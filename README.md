# Diablo English Coach

給《Diablo Immortal》使用的本機即時英文教練。程式會自動讀取你框選的字幕區，顯示：

- 螢幕上的英文原句
- A2–B1 程度的簡單英文改寫
- 不增加劇情資訊的繁體中文解釋
- 每句最多 3 個值得記的單字
- 預設使用較自然的 Edge 線上神經語音，也保留 Windows 離線語音

程式不讀遊戲記憶體、不控制角色、不連攻略網站。模型只會收到已經出現在螢幕上的任務與對話。

## 第一次使用

1. 雙擊 `安裝本機模型.cmd`。它會從 Ollama 官方網站安裝 Ollama，並下載約 2 GB 的 `qwen3.5:2b-q4_K_M`。
2. 將 Diablo Immortal 設為英文介面、英文語音、英文字幕，以及「視窗化全螢幕」。
3. 開啟遊戲後，雙擊 `啟動英文教練.cmd`。
4. 按「設定 → 辨識範圍」可以分別設定「對話字幕區」與「任務目標區」。預設任務區已針對 1920×1080 左側任務面板調整。
5. 選「測試兩個辨識區」，確認能讀到任務或對話後，按「開啟」。

只需要在第一次或遊戲解析度改變時重新框選，不需要手動截圖。

## 遊戲內長條介面

- 預設出現在遊戲畫面下方中央，避開上方中央的怪物名稱與血條；舊版儲存於上方中央的位置也會自動遷移。
- 視窗寬度約為螢幕的 64%，高度 158 像素，採無邊框圓角設計。
- 主畫面只留下「開啟／關閉」「設定」與關閉按鈕。
- 預設透明度為 80%；其他透明度、辨識範圍、聲音、位置與角色偏好都收在「設定」。
- 拖曳 `ENGLISH COACH` 標題或狀態文字即可移動位置，程式會記住座標。
- 教練長條已排除在 OCR 擷取之外，不會把自己的翻譯當成遊戲字幕。
- 辨識框選器會固定覆蓋遊戲客戶區，不會因工作列或多螢幕縮放而突然跳位。

## 任務、英文與配裝教學

- 對話區出現新句子：自動提供簡單英文、繁中、單字與一則短英文知識。
- 任務區出現新目標：主動用「現在要做：」解釋目前行動，並教一個任務常用片語。
- 第一次任務與之後每三個新任務，低負載時會額外穿插一則簡短流派或裝備提示，不增加模型呼叫。
- 「設定」可選職業與「輕鬆推進／召喚流／傷害優先／生存優先」。預設依目前角色使用「死靈法師＋輕鬆推進」。
- 配裝提示以核心技能、Damage、Life 與傳奇效果的搭配為主，不會假裝知道尚未顯示的裝備或提供容易過期的排行榜。

任務模型只接收可見文字，提示詞要求資訊不足時回答「目前畫面沒有說明」，並為常見任務指令提供固定校正。OCR 和小模型仍可能出錯，請以遊戲原文為準。配裝提示是一般練等建議，沒有掃描背包、比較兩件裝備數值或保證當季最強流派。

## 空閒時持續教學

- 無待處理任務／對話、CPU 低於 55%、非空白鍵已停用至少 10 秒，且連續安靜至少 10 秒時，約每 45 秒提供一則短教學。
- 循環內容包括：任務／對話常用英文、最近辨識過的單字（最多 24 個）、一般流派與選裝觀念。這是複習輪播，不代表已測量你的熟練程度。
- 對話區仍有英文時，暫緩額外教學；新任務優先。忙碌時跳過的輪播不堆積、不一次播完。
- 預習的是常見句型與玩法概念，不是尚未發生的劇情、任務或裝備掉落。
- 內容只更新右側欄位，保留目前任務與中文指引。沿用你的中／英文朗讀設定。
- 教材為程式內的小型題材庫，不增加 LLM 呼叫、模型下載或第三個 OCR 區域；重新開啟程式後輪播進度重置。
- 「設定 → 自動提供流派／裝備提示」只控制個別化配裝提示，關閉後仍保留遊戲英文詞彙教學。

## 聲音與速度

按主畫面的「設定 → 聲音與語速」可以選擇：

- 繁中小雨：較年輕、活潑的台灣女聲，預設使用。
- 繁中曉臻：比較溫和自然。
- 英文 Ana：較年輕的美式女聲，適合短句跟讀。
- 英文 Jenny／Aria：比較成熟、清楚。
- 語速可在 `-30%` 到 `+50%` 調整；預設為 `+18%`。
- 沒有網路時可取消「使用自然女聲」，立即改用電腦內的 Yating／Zira。

中英文朗讀都遵守負載保護；模型回答完成且適合教學時才朗讀，空閒教材不必等模型。Edge 自然語音不需要 API key，但會將當前要朗讀的句子送到 Microsoft。連線失敗時會自動使用 Windows 離線語音。

## 自動負載模式

- 你持續使用非空白鍵的鍵盤操作，或整體 CPU 超過約 72% 時，教練會把背景掃描放慢到每 2.8 秒一次。
- `Space` 被視為推進對話，不會觸發戰鬥忙碌狀態；WASD、技能鍵與其他鍵盤按鍵才會延後補充。
- 忙碌時只記住新任務與對話，不啟動本機模型、不朗讀；最後一次戰鬥／操作按鍵約 2.5 秒後且 CPU 降低時才補充教學。
- 鍵盤偵測不使用全域 Hook，也不保存按鍵內容，只保留「最後一次非空白鍵操作的時間」。
- Ollama 回答期間會暫停背景 OCR，避免 OCR 和語言模型同時搶 CPU。
- 發現新的操作按鍵或離開遊戲時會取消等待中的模型請求，稍後重試；請求取消不代表 Ollama 已瞬間停止所有計算。
- 「關閉」停止掃描、朗讀與鍵盤輪詢，取消請求並丟棄晚到的回答。辨識測試只測 OCR，不會偷偷開啟模型或語音。
- 切換到其他程式、開設定時不做背景教學。鍵盤判斷不等同戰鬥偵測；滑鼠戰鬥、手把或 GPU 忙碌仍可能漏判。

## 為這台筆電調整的效能配置

- 對話區每 1.1 秒掃描一次；變化較慢的任務區每三輪掃描一次，不錄影、不保存畫面。
- OCR：Windows 內建模型，使用 CPU／內顯顯示路徑。
- LLM：預設強制 CPU 推論、2 個執行緒，避免占用 MX330 的 2 GB 顯存與所有 CPU 核心；翻譯可能稍慢。
- Diablo Immortal：在 Windows「圖形設定」中設為高效能，交給 MX330。
- 教練視窗：已排除在螢幕擷取之外，不會讀到自己的翻譯。

Iris Xe 與 MX330 能分擔不同工作，但不能合併顯存或共同載入同一個模型。預設配置讓 MX330 專心跑遊戲，Iris Xe 負責桌面合成，CPU／16 GB RAM 跑 2B 模型。

## 沒有 Ollama 時

OCR、英文原句和少量 Diablo 常用詞仍可用，但不會有完整繁中翻譯。執行 `安裝本機模型.cmd` 後即可啟用完整功能。

## 常見問題

### 找不到遊戲視窗

先啟動 Diablo Immortal，不要最小化，並使用視窗化全螢幕模式。

### 辨識出一堆介面文字

重新框選更小的字幕區，只保留畫面下方中央的對話字幕。

### 英文的 I、l 偶爾認錯

這台電腦目前只有繁中 Windows OCR；它可以讀英文，但準確度稍低。可到 Windows 的「語言與地區」加入 English (United States) 的基本輸入與光學字元辨識功能，再重新啟動教練。

### 翻譯很慢

第一次載入模型通常最慢。此版本一次只處理一個模型請求，OCR 暫存最新任務與對話，空閒才處理。較慢的掃描可能漏掉短暫字幕；這是降低干擾的取捨。尚未測量遊戲 FPS，不保證完全不影響效能。

### 擔心爆雷

教練不保存劇情進度、不在遊戲中使用網路搜尋，也不會取得下一句。補充教材不含後續故事。

## 一般建議依據

配裝教學採技能搭配與生存／傷害取捨，不提供即時版本排行榜。背景參考：[Blizzard 裝備設計說明（早期資料，不沿用舊數值）](https://news.blizzard.com/en-us/article/23574266/itemization-in-diablo-immortal)、[Blizzard 傳奇效果範例](https://news.blizzard.com/en-us/article/24246207/sing-the-ballad-of-the-moon)。實際技能、解鎖條件與屬性仍以你遊戲內的說明為準。

## 開發與建置

需要 .NET 10 SDK：

```powershell
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained true -o publish
```

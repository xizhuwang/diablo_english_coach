# Diablo English Coach

給《Diablo Immortal》使用的本機即時英文教練。程式會自動讀取你框選的字幕區，顯示：

- 螢幕上的英文原句
- A2–B1 程度的簡單英文改寫
- 不增加劇情資訊的繁體中文解釋
- 每句最多 3 個值得記的單字
- 預設使用較自然的 Edge 線上神經語音，也保留 Windows 離線語音

程式不讀遊戲記憶體、不控制角色、不連攻略網站。模型一次只會收到已經出現在螢幕上的一句字幕。

## 第一次使用

1. 雙擊 `安裝本機模型.cmd`。它會從 Ollama 官方網站安裝 Ollama，並下載約 2 GB 的 `qwen3.5:2b-q4_K_M`。
2. 將 Diablo Immortal 設為英文介面、英文語音、英文字幕，以及「視窗化全螢幕」。
3. 開啟遊戲後，雙擊 `啟動英文教練.cmd`。
4. 按「範圍」可以分別設定「對話字幕區」與「任務目標區」。預設任務區已針對 1920×1080 左側任務面板調整，位置不準時再重設。
5. 選「測試兩個辨識區」，確認能讀到任務或對話後，按 `▶` 開始自動教學。

只需要在第一次或遊戲解析度改變時重新框選，不需要手動截圖。

## 遊戲內長條介面

- 預設出現在遊戲畫面上方中央，避開左側角色／任務與右側小地圖。
- 視窗寬度約為螢幕的 64%，高度 158 像素，採無邊框圓角設計。
- 預設透明度為 80%；按工具列上的百分比可在 65%、80%、92% 間切換。
- 拖曳 `ENGLISH COACH` 標題或狀態文字即可移動位置，程式會記住座標。
- 按 `▴` 可收成只有 38 像素高的控制列，再按 `▾` 展開。
- 教練長條已排除在 OCR 擷取之外，不會把自己的翻譯當成遊戲字幕。

## 任務指引與互動教學

- 對話區出現新句子：自動提供簡單英文、繁中、單字與一則短英文知識。
- 任務區出現新目標：主動用「現在要做：」解釋目前行動，並教一個任務常用片語。
- `下一步`：重新詢問目前該做什麼，只根據螢幕可見的任務文字回答。
- `挑戰`：使用剛看到的英文出一題 A/B/C 小測驗，不會先公布答案。
- `問`：可以問中文或英文，也可以輸入 A／B／C 回答上一題；教練會保留最近四輪互動。

任務教練不連攻略網站，也不知道尚未顯示的任務、人物身分或後續劇情。若畫面資訊不足，它會回答「目前畫面沒有說明」。

## 聲音與速度

按主畫面的「聲音設定」可以選擇：

- 繁中小雨：較年輕、活潑的台灣女聲，預設使用。
- 繁中曉臻：比較溫和自然。
- 英文 Ana：較年輕的美式女聲，適合短句跟讀。
- 英文 Jenny／Aria：比較成熟、清楚。
- 語速可在 `-30%` 到 `+50%` 調整；預設為 `+18%`。
- 沒有網路時可取消「使用自然女聲」，立即改用電腦內的 Yating／Zira。

若選「自動念英文」，OCR 讀到字幕後會立刻發音，不必等待翻譯；自動念中文則要先等待本機模型完成翻譯。Edge 自然語音不需要 API key，但會將當前要朗讀的句子送到 Microsoft。連線失敗時會自動使用 Windows 離線語音。

## 為這台筆電調整的效能配置

- 對話區每 1.1 秒掃描一次；變化較慢的任務區每三輪掃描一次，不錄影、不保存畫面。
- OCR：Windows 內建模型，使用 CPU／內顯顯示路徑。
- LLM：預設強制 CPU 推論，避免占用 MX330 的 2 GB 顯存。
- Diablo Immortal：在 Windows「圖形設定」中設為高效能，交給 MX330。
- 教練視窗：已排除在螢幕擷取之外，不會讀到自己的翻譯。

Iris Xe 與 MX330 能分擔不同工作，但不能合併顯存或共同載入同一個模型。預設配置讓 MX330 專心跑遊戲，Iris Xe 負責桌面合成，CPU／16 GB RAM 跑 2B 模型。

## 沒有 Ollama 時

OCR、英文原句和少量 Diablo 常用詞仍可用，但不會有完整繁中翻譯。執行 `安裝本機模型.cmd` 後即可啟用完整功能。

## 常見問題

### 找不到遊戲視窗

先啟動 Diablo Immortal，不要最小化，並使用視窗化全螢幕模式。

### 辨識出一堆介面文字

重新框選更小的字幕區，只保留畫面下方中央的對話字幕。

### 英文的 I、l 偶爾認錯

這台電腦目前只有繁中 Windows OCR；它可以讀英文，但準確度稍低。可到 Windows 的「語言與地區」加入 English (United States) 的基本輸入與光學字元辨識功能，再重新啟動教練。

### 翻譯很慢

第一次載入模型通常最慢。此版本會取消過時字幕的翻譯，永遠優先處理最新一句。遊戲激烈時可先按暫停，進劇情對話再開啟。

### 擔心爆雷

教練不保存任務進度、不使用網路搜尋，也不會取得下一句。它只做當前句子的簡化、翻譯與單字解釋。

## 開發與建置

需要 .NET 10 SDK：

```powershell
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained true -o publish
```
